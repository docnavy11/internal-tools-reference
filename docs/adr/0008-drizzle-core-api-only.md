# 0008 Drizzle ORM, using the core query builder only

Accepted, 2026-09-04

## Context

Drizzle is the common TypeScript choice for Postgres with SQL-shaped queries and
generated migrations. It is still 0.x and its relational query API has been
reworked. The core `select`, `insert`, `update`, `delete`, `pgTable` and the
`drizzle-kit generate` and `migrate` commands have been stable and the builder
knows them well.

## Decision

Use Drizzle for table definitions, migrations and the core query builder. Do not
use the relational queries API (`db.query.<table>.findMany` with `with`), and do
not use `drizzle-zod`. Joins are written explicitly. Zod schemas are written by
hand in `shared`.

## Consequences

- Queries read like SQL and are easy for any developer to follow.
- Some duplication between Drizzle tables and Zod schemas. Accepted for clarity;
  a test per feature asserts a sample row satisfies the Zod schema to catch drift.
- Migrations are SQL files in `drizzle/`, generated by `drizzle-kit generate`,
  reviewed, committed, never edited once applied anywhere.
